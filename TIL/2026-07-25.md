## Terraform + boto3 연계 실습

### 배운 것

**subprocess 라이브러리**
- Python에서 터미널 명령어 실행하는 내장 라이브러리
- 별도 설치 불필요
- `subprocess.run()` 으로 명령어 실행
- `cwd` 옵션으로 실행 경로 지정
- `result.stdout.strip()` 으로 출력값 가져오기

**Terraform + boto3 연계 흐름**
- `terraform apply` 로 EC2 생성
- `terraform output instance_id` 로 instance_id 추출
- subprocess로 Python에서 terraform output 실행
- 가져온 instance_id로 boto3 EC2 조회

**Tags 구조**
- Tags는 리스트 안에 딕셔너리 구조
- `[{'Key': 'Name', 'Value': 'jinchul-terraform-ec2'}]`
- for문으로 순회해서 원하는 Key 찾아야 함

### 느낀 것
- Terraform이랑 boto3를 연계하면 인프라 생성부터 제어까지 자동화 가능
- 구글링해서 직접 찾아가며 짜는 게 오래 걸려도 기억에 남음
