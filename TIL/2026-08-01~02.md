## Terraform 모듈화 완성

### 배운 것

**모듈화 구조**
terraform/
├── main.tf # 모듈 호출
├── variables.tf # 상위 변수
├── outputs.tf # 상위 출력
└── modules/
├── vpc/
│ ├── main.tf # VPC, Subnet, IGW, Route Table
│ ├── variables.tf
│ └── outputs.tf
└── ec2/
├── main.tf # Security Group, EC2
├── variables.tf
└── outputs.tf

**핵심 개념**
- 모듈에서 `terraform`, `provider` 블록 제거
- 모듈 간 값 전달: `module.vpc.vpc_id` 형식으로 참조
- `default` 없는 변수 = 필수 변수 (상위에서 반드시 넘겨줘야 함)
- 같은 모듈 안에서 만든 리소스는 변수로 받을 필요 없음

**모듈 호출 방식**
```hcl
module "vpc" {
  source            = "./modules/vpc"
  vpc_cidr          = "10.0.0.0/16"
  subnet_cidr       = "10.0.1.0/24"
  availability_zone = "ap-northeast-2a"
}

module "ec2" {
  source        = "./modules/ec2"
  vpc_id        = module.vpc.vpc_id
  subnet_id     = module.vpc.subnet_id
  instance_type = "t3.micro"
}
```

### 트러블슈팅
- 문제: `security_group_id` required 에러
- 원인: variables.tf에 정의된 변수를 상위에서 안 넘겨줌
- 해결: EC2 모듈 안에서 직접 생성하므로 변수 제거
