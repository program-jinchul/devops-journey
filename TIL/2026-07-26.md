## Terraform으로 AWS 인프라 전체 구성

### 구성한 리소스
- VPC (10.0.0.0/16)
- Public Subnet (10.0.1.0/24, ap-northeast-2a)
- Internet Gateway
- Route Table (0.0.0.0/0 → IGW)
- Route Table Association (Subnet 연결)
- Security Group (SSH 22, HTTP 80 인바운드)
- EC2 (Amazon Linux 2023, t3.micro)

### 배운 것

**Terraform 리소스 참조**
- 다른 리소스 참조할 때 `리소스타입.리소스이름.속성` 형식
- 따옴표 안에 넣으면 문자열로 인식되어 에러 발생

**자주 한 실수**
- 타자 실수가 잦아서 terraform plan 명령어로 먼저 실행해볼 때 안되는 경우가 있었음

### 느낀 것
- 콘솔에서 하나하나 클릭했던 게 코드 한 번으로 해결됨
- terraform destroy로 7개 리소스 한번에 삭제
- IaC의 강력함을 직접 체감함
