# S3 (Simple Storage Service)

## 개념
AWS에서 제공하는 객체 스토리지 서비스. 파일, 이미지, 로그 등 어떤 형태의 데이터든 저장 가능하다.

## 구성 요소

### Bucket
- S3의 기본 저장 단위. 전 세계에서 유일한 이름이어야 함
- 실습에서 사용: `jinchul-devops-bucket`

### Object
- 버킷 안에 저장되는 파일 단위
- Key(파일명), Value(파일 내용)으로 구성

### Public Access
- 기본적으로 모든 퍼블릭 액세스 차단
- Block all public access 설정으로 보안 유지

## 실습 구성
- S3 버킷 생성
- boto3로 파일 업로드, 목록 조회, 삭제 자동화

## boto3 코드
```python
s3 = boto3.client('s3', region_name='ap-northeast-2')

# 업로드
s3.upload_file('파일경로', 'jinchul-devops-bucket', '저장될파일명')

# 목록 조회
response = s3.list_objects_v2(Bucket='jinchul-devops-bucket')

# 삭제
s3.delete_object(Bucket='jinchul-devops-bucket', Key='파일명')
```
